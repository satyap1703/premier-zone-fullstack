# Premier Zone

Premier Zone is a full-stack Premier League web application that allows users to explore Premier League teams and players.

## Features

- View Premier League teams
- Search for teams
- View players by team
- Search players by name
- Filter players by position
- Filter players by nationality
- REST API powered by Spring Boot
- React-based frontend
- PostgreSQL database integration
- Responsive and interactive user interface

## Tech Stack

### Frontend
- React
- JavaScript
- HTML
- CSS / SCSS
- Axios
- React Router

### Backend
- Java
- Spring Boot
- Spring Data JPA
- REST APIs
- Maven

### Database
- PostgreSQL
